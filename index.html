Sobre mí

Soy estudiante de 8.º semestre de Ingeniería Informática en la UNET (Venezuela), a unos ocho meses de graduarme, y desarrollador full-stack con preferencia por el backend. Me gusta llevar los proyectos de principio a fin: definir el alcance, modelar la base de datos, construir la API y la interfaz, escribir pruebas y desplegar.

Trabajo sobre todo con TypeScript (Next.js, React, Node/Express) y Python (FastAPI), con PostgreSQL y Supabase como base de datos. Cuido cosas que no se ven pero importan: seguridad a nivel de filas (RLS), sesiones con cookies HTTP-only, migraciones versionadas, pruebas unitarias y E2E, y documentación de decisiones técnicas.

Busco mi primer empleo o prácticas en tech, en un equipo donde pueda aportar desde el primer día y seguir aprendiendo de gente con más experiencia.

Proyectos destacados

Habit Tracker — web PWA + app móvil

Demo Código
Problema
Quería una app de hábitos que funcione igual en el navegador y en el móvil, sin perder datos y con estadísticas reales de progreso.
Qué construí
Una web responsive instalable como PWA y una app móvil con Expo que comparten la lógica en un monorepo. Permite crear y archivar hábitos sin perder historial, marcar el día, ver un calendario mensual y estadísticas de 7, 30 y 90 días con rachas. Incluye registro, login con Google, verificación por código y recordatorios en el móvil.
Resultado
MVP web completo y desplegado en Vercel, con entornos de preview por PR y producción; app Android en beta interna contra producción. Pruebas unitarias, E2E con auditoría de accesibilidad y pruebas de seguridad de la base de datos.

  • Tailwind v4

Expense Track — gestor de gastos full-stack

Código
Problema
Llevar el control de los gastos personales de forma segura, de modo que cada usuario vea y modifique solo sus propios datos.
Qué construí
Una aplicación full-stack con registro, inicio y cierre de sesión, rutas protegidas y CRUD de gastos con filtros por fecha, monto, categoría y búsqueda. El backend es una API REST propia y el frontend un dashboard en React.
Resultado
API con aislamiento de datos por usuario, validación en todas las entradas, migraciones versionadas y sesión persistente segura, lista para levantar en local con Docker.
